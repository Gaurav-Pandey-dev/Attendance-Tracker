# Attendance Tracker App

An Android-based Attendance Tracker application developed using **Kotlin** and Android Studio. This application helps users manage student attendance, mark students as present or absent, and maintain attendance records in an organized way.

## Features
- Add and manage student records.
- Mark students as Present or Absent.
- View attendance records.
- Track student attendance history.
- Simple and user-friendly interface.
- Store attendance data locally.

## Technologies Used
- Kotlin
- Android Studio
- XML
- SQLite Database

## Purpose
The main objective of this project is to simplify attendance management and reduce manual record-keeping through an Android application.

## Future Improvements
- Attendance percentage calculation.
- Date-wise attendance reports.
- Search and filter students.
- Export attendance reports.
