# Attendance Tracker – Personal Attendance Record Keeper

An Android application developed using Kotlin that helps individuals maintain and manage their personal attendance records digitally.

The application is designed for both students and working professionals who want to record their daily attendance and keep track of their attendance history for future reference.

## Key Features
- Record personal daily attendance.
- Maintain attendance history.
- Easy attendance management.
- Review previously saved records.
- Simple and user-friendly interface.

## Technologies
- Kotlin
- Android Studio
- XML
- SQLite Database
